# Лабораторна робота №5 — варіант 2

**Тема:** семантична сегментація пошкоджень будівель на супутникових знімках xBD.

## Мета й підхід

Для кожного пікселя модель визначає один із п’яти класів: фон, будівля без пошкоджень, незначні, значні пошкодження або зруйнована будівля. Використано U-Net із кодером EfficientNet-B3, попередньо навченим на ImageNet. Порівняно функції втрат Cross-Entropy (CE) та CE + Dice, умови до/після події й інференс цілим кадром та перекривними тайлами.

## Як запустити

Потрібні Python 3.10 або новіший, PyTorch із відповідною версією CUDA (або CPU), `segmentation-models-pytorch`, Pillow, NumPy та Matplotlib. Дані xBD не включені до репозиторію. Завантажте й розпакуйте набір даних окремо, після чого виконайте з кореневої папки репозиторію:

```powershell
python -m pip install torch segmentation-models-pytorch pillow numpy matplotlib
python lab5_variant2_xbd.py prepare --data PATH_TO_XBD --output xbd_prepared --seed 42
python lab5_variant2_xbd.py train --manifest xbd_prepared/manifest.csv --output runs/ce_dice --epochs 30 --size 512 --batch-size 4 --workers 2 --seed 42 --dice-loss
python lab5_variant2_xbd.py evaluate --manifest xbd_prepared/manifest.csv --checkpoint runs/ce_dice/best.pt --split test --output runs/test
```

Шляхи до вихідних папок xBD можуть відрізнятися залежно від того, як саме розпаковано набір. Перевірте `python lab5_variant2_xbd.py prepare --help` і `python lab5_variant2_xbd.py --help` для параметрів та доступних команд. Для запуску навчання рекомендовано GPU; навчання з нуля на CPU буде значно повільнішим.

## Результати

Основні моделі навчалися 30 епох на тому самому розбитті даних. На тестовій підмножині CE + Dice отримала **mIoU 0,4341**, CE — **0,4128**. Для CE + Dice піксельна точність становить **0,9543**, boundary F1 — **0,5448**. Тайловий інференс дав mIoU **0,4191** і boundary F1 **0,5579** проти **0,4341** та **0,5447** для повного кадру: межі трохи кращі, але загальний mIoU нижчий.

Оцінювання виконане на одному розбитті й одному seed. Клас незначних пошкоджень лишається складним; докладні метрики за класами, приклади передбачень, аналіз сенсорів і обмеження наведено у DOCX-звіті. Досліди з обмеженою розміткою виконувалися за окремим коротшим п’яти-епоховим протоколом.
